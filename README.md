
# 🧮 Calculator Using Python

A simple and user-friendly calculator project developed using Python. It performs various mathematical operations and handles invalid inputs and division by zero.

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- % Modulus
- 🔢 Power
- √ Square Root
- 📊 Percentage
- ❌ Division by zero handling
- ⚠️ Invalid input handling
- 🔄 Continuous calculations
- 🚪 Exit option

## 🛠️ Technologies Used

- Python
- Math module
- Functions
- Loops
- Conditional statements
- Exception handling

## ▶️ How to Run

1. Install Python.
2. Open the project in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
python calculator.py
